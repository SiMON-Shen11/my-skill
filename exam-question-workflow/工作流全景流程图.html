4/7

版面分析（layout_analysis.py）—— 核心步骤

从 OCR 识别大题标题（期末打卡 DAY N / 第X部分 / 教材层级标题）、题号、页脚，逐题切定「题号→下一题」范围，并对每题做题型判定（按老师锁定标准，执行级短路：每步命中即返回，不再执行后续判断）：
🔲 表格页检测（前置分支）：页面同时存在「类型一/二/三」分类标签（左栏）+「教材变式/母题」（右栏）→ 判定为镶嵌多个题目的大表格页 → 跳过常规题号检测，将 section 标题 + 整个表格作为一道解答题整体切割（标记 is_table，跳过跨页判定）。
解决：左栏"1.2.3."类型子问被误识别为题号、右栏"【教材变式N】"格式不匹配题号正则被漏检。
① 选择题：只检测选项行（A./B./C./D. 或 (A)(B)(C)(D)）→ 命中即返回选择题，跳过像素横线检测与解答判断
　　↓ 未命中
② 填空题：只看横线，不涉及解答关键词/问号 → 有子问则每个子问都有横线（像素检测起始不侵入上一行文字），或无子问题后有 ____ 横线（OCR 或像素检测）→ 命中即返回填空题，跳过解答判断（即使有"求/计算/证明/问号"也判填空）
　　像素横线防误判：横线上方0-3px有笔画（文字底横）或左右6px内有笔画（汉字"一"）→ 排除，不误判为填空横线
　　↓ 未命中
③ 解答题：无横线时才用解答特征判断（此时才计算关键词/问号，执行级短路）→ 有子问(非全横线) / 命中 求/证明/计算… 关键词 / 以？结尾 → 返回解答题
　　↓ 未命中
④ 未分类 → 进 pending（交 Agent 视觉判断）
含跨页处理：末题内容底距页底<400 且下页首题 y>200 → 合并下页顶部一起判定（选项在下一页的选择题不再误判）。
▶ 产物：markers.json（大题/题号/页脚标记 + 每题题型 + 未分类 pending 列表）
▼
5/7

图形边界检测（figure_detection.py）

通过「图N」标题定位图形位置，形态学闭运算连接图中分散点线，得到图形真实边界（保证几何图 / 坐标系切图时不被切掉）。
▶ 产物：figures.json（各图形边界框）
▼
6/7

题目切分（crop.py）—— 完整性优先

按 markers + figures 把每题切成长条图，核心原则：宁可相邻题在图形/分式区域重叠，也不让任何一题自身内容被截断。
边界规则（按优先级）修复的问题
上边界① 题号−28px → ② 有图形则延伸到图形顶−10px → ③ 不侵入上一大题标题 → ④ 不低于上一题下边界 → ⑤ 题号上方80px内有OCR内容（行列式首行/分式分子）→ 扩展到内容顶−8px行列式首行/分式分子在题号上方被裁
下边界① 内容底+50px → ② 夹紧到下一题题号−2px → ③ 不越过大题标题/页脚 → ④ 下一题内容向上延伸（大括号/分子比题号高）→ 夹紧到下一题内容顶−2px → ⑤ 本题含分式且分母在下一题题号下方 → 取max，最多延伸50px方程组分子被截断混入上一题；分式分母被下一题题号裁掉
左右默认/auto-margin边界 ∪ 本页OCR文本实际范围，各加10-15px留白宽版心左右边缘字符被裁
跨页末题内容底>页高−400px 且 下页首题y>200px → 上页题号到页底 + 下页页顶到下一题题号前，垂直拼接跨页题题干/选项被分到两页
▶ 分式检测：垂直堆叠的分子/分母OCR块对（间距−2~14px、x重叠>4px、单块宽<150px）→ 自动扩展上下边界；▶ 产物：output/questions/{选择题,填空题,解答题}/ + meta.json
6.5

Agent 联动（未分类题看图判定）

若存在未分类题：导出切图到 output/pending/ + 清单 pending_questions.json → 暂停 → 你看图 / Agent 视觉判断题型 → 填写 pending_types.json → 用 --pending-types 重跑，回填 markers.json 后再进第 7 步。
▶ 循环：导出待判图 → 判定 → 回填重跑（期末打卡 101 题仅 1 题走此路径，其余自动判定）

7/7

层级命名 + 归档（hierarchy_tracker.py + naming.py）

教材：按 tree.json 层级状态机给每题定位到「第X章/第X节/…/题型」；试卷：仅按题型归档。统一命名复制到 output_hier。
▶ 产物：output_hier/选择题/选择题_第01题.png … + final_meta.json（题号 ↔ 图片路径映射）
