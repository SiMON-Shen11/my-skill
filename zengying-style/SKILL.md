# 曾颖式冷幽默观点文（"颖学"仿写）

帮用户用脱口秀式冷幽默表达观点：尖锐、好笑、克制。核心只有一句：**语气负责平静，事实负责离谱。** 情绪是读者的活儿，作者只递事实。

动笔前先读 `references/style-guide.md`（八律详解与正反例）；列提纲时用 `references/toolkit.md`（句式工具箱）；找不到感觉就读 `references/examples.md`（原创范文）。

## 第一步：确认三件事

1. **观点内核**：用一句话说清用户要表达什么。模糊就先问一句，别猜——文风可以调，观点不能歪。
2. **讽刺对象**：只能是现象、制度、公开言行。涉及具体真实个人时，只针对其公开言行，不碰隐私、外貌、身体。
3. **锚点物件**：给这篇文找一个具体小物件当"弹药"（报名表、工牌、会员弹窗、截图、传单……），全篇至少出现两次——开头立起来，结尾 callback 回访。颖学的笑点几乎都长在具体物件上，而不是观点上。

## 参数（用户不说就按默认）

- **体量**：小作文 500–1000 字（默认）／短打 ≤200 字
- **毒舌等级**：微辣（温和调侃）／中辣（默认，明讽暗刺）／变态辣（火力全开，依然不带脏字）

## 文风八律（浓缩版；详解与正反例见 references/style-guide.md）

1. **一本正经讲荒诞**：语气越平，事实越离谱。删掉感叹号和"竟然／居然／太离谱了"这类情绪标注词。
2. **自嘲垫底再刺人**：先把自己放进笑话，读者才允许你刺别人；全程只损对方会显得刻薄。
3. **细节当弹药**：好笑的是名词和数字，不是形容词。"周五下午五点半发的通知"永远好过"总是不合时宜地发通知"。
4. **铺垫—反转**：短句、口语，反转词放句尾。读者是按句号付笑的。
5. **冷收尾**：不总结、不升华、不喊口号、不"总之"。结尾要么 callback 锚点物件，要么一个轻飘飘的冷事实。
6. **假装同意再拆台**：用"对／好的／真棒／我非常想去"起手，把刀藏在顺从里。
7. **黑色幽默不带脏字**：杀伤力靠事实错位，不靠骂。想骂的时候，改成摆一个更狠的事实。
8. **不解释笑点、不堆热梗**：梗说完就走；同一个梗全篇最多正面用一次＋callback 一次。

## 五步写作流程

1. 提炼观点一句话内核（不清楚就问用户）
2. 定讽刺对象＋荒诞点＋锚点物件
3. 列提纲：每段 = 1 个论点 + 1 个梗；从 toolkit 挑 3–5 个句式；开头用"观察式断言"钩子，结尾用 callback
4. 写初稿
5. 过下方自检清单，不过关就改，最多两轮

## 自检清单（全部通过才算完成）

- [ ] 每 100 字至少 1 个梗
- [ ] 结尾是冷的：无口号、无升华、无"总之"
- [ ] 细节具体：有名词、数字、物件；没有"某些人／总是／让人"式空话
- [ ] 讽刺对事不对人：无隐私、无外貌攻击、无脏字、无编造事实
- [ ] 通读一遍：语气平静吗？解释笑点的句子全删了吗？
- [ ] 篇幅符合所选体量

## 边界（每次都要守住）

- 输出是**风格仿写创作**，不是曾颖本人的言论：不署其名、不暗示来自本人。
- 只针对现象与公开言行：不扒隐私、不造谣、不诽谤、不攻击外貌与身体。
- 不逐字复制曾颖的原文；`references/examples.md` 中的范文均为原创仿写，仅用于校准文风。
